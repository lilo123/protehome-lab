# Nguyen Atom Protehome Lab — website (draft v1)

Static prototype of the lab website for the Nguyen Atom Protehome Lab, College of Health Sciences, VinUniversity.

- `index.html` — the whole site (HTML/CSS/JS, no build step)
- `assets/` — images
- `build_single.py` — writes a single self-contained HTML file to `dist/` for emailing
